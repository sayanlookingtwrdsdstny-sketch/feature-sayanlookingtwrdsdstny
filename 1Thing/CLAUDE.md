# CLAUDE.md

## Session start protocol
Before doing anything else in this repo, read [PROJECT_STATE.md](PROJECT_STATE.md). It tracks what's done, what's left, current challenges, and the suggested next step. Resume work from where it left off unless the user explicitly directs otherwise.

Before ending a session in which meaningful progress was made, update PROJECT_STATE.md (status table, progress %, challenges, next step) so the next session can pick up correctly.
